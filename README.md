# The Bellevue Homes

Static rebuild of `https://www.thebellevuehomes.com` prepared for Firebase Hosting.

## Local preview

```bash
npm run preview
```

## Firebase deploy

1. Install the Firebase CLI or use `npx firebase-tools`.
2. Log in:

```bash
npm run firebase:login
```

3. Initialize Hosting against your Firebase project if this repo is not yet linked:

```bash
npm run firebase:init
```

4. Deploy:

```bash
npm run deploy
```
